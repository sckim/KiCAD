# 시뮬레이션 2. AC Analysis — 직렬 RLC 대역통과 필터

**AC 해석(`.ac`)** 은 입력 신호의 주파수를 바꿔 가며 출력의 크기(이득)와 위상이 어떻게 변하는지를 계산한다. 결과는 가로축이 주파수인 그래프(보드 선도, Bode plot)로 나타난다.
이 예제에서는 C, L, R을 직렬로 연결한 **대역통과 필터(band-pass filter)** 의 주파수 특성을 본다.

> 먼저 [Transient_Analysis](../Transient_Analysis/)와 [Frequency_Analysis](../Frequency_Analysis/)(1차 RC 필터)를 해 보면 이해가 쉽다.

---

## 1. 회로

```
 VCC ──┤├──── V_CL ──∩∩∩──┬── Vo
  │    C1 1µF       L1 0.1H │
 V1 (사인파)               R1 1kΩ
  │                         │
 GND ───────────────────────┘
```

| 참조 번호 | 부품 | 값 | 비고 |
|---|---|---|---|
| V1 | 사인파 전압원 (`Simulation_SPICE:VSIN`) | `dc=0 ampl=5 f=100 ac=1` | |
| C1 | 커패시터 | 1 µF | 회로도에 `01.uF`로 적혀 있으며 1.0 µF로 읽힌다 |
| L1 | 인덕터 | 0.1 H | |
| R1 | 저항 | 1 kΩ | 출력 `Vo`는 R1 양단 전압 |

> V1의 `ac=1`은 **AC 해석에 쓰는 입력 크기(1 V)** 이다. `ampl=5`, `f=100`은 과도 해석(`.tran`)에서만 쓰인다. 입력이 1 V이므로 AC 해석 결과의 `V(/Vo)`는 곧 **이득(Vo/Vin)** 이 된다.

## 2. 이론

- 낮은 주파수에서는 C가, 높은 주파수에서는 L이 전류를 막는다. 두 임피던스가 서로 상쇄되는 **공진 주파수** 에서만 신호가 그대로 통과한다.

```
공진 주파수   f0 = 1 / (2π √(L C)) = 1 / (2π √(0.1 × 1µ)) ≈ 503 Hz
대역폭        BW = R / (2π L)      = 1000 / (2π × 0.1)     ≈ 1.59 kHz
품질 계수     Q  = f0 / BW                                  ≈ 0.32
```

## 3. 시뮬레이션 실행

1. `AC_Analysis.kicad_pro`를 열고 **Inspect → Simulator** 를 연다.
2. 저장된 해석은 **`.ac dec 10 1 100k`** 이다. 1 Hz ~ 100 kHz를 로그 눈금으로, 10배(decade)마다 10개 점씩 계산한다는 뜻이다.
3. **Run Simulation** (▶)을 누른다. 작업 파일에 `V(/Vo)`의 이득(gain, dB)과 위상(phase)이 이미 등록되어 있다.
4. 저장된 커서 두 개가 −3 dB 지점 근처에 놓여 있다. 커서를 움직여 이득이 가장 큰 지점과 −3 dB 지점을 찾는다.

## 4. 결과

| 항목 | 시뮬레이션 | 계산값 |
|---|---|---|
| 최대 이득 | **0 dB (1.00)**, 501 Hz 부근 | 공진에서 1 |
| 위상이 0°인 주파수 | **503 Hz** | f0 = 503 Hz |
| 아래쪽 −3 dB 주파수 f_L | **146 Hz** | |
| 위쪽 −3 dB 주파수 f_H | **1.73 kHz** | |
| 대역폭 f_H − f_L | **1.59 kHz** | R / (2πL) = 1.59 kHz |

위상은 낮은 주파수에서 +90°, 공진에서 0°, 높은 주파수에서 −90°로 바뀐다.

## 5. 해 보기

1. C1을 `0.1u`로 바꾼다. f0가 √10배(≈ 1.59 kHz)로 올라가는 것을 확인한다.
2. R1을 `100`(100 Ω)으로 바꾼다. 대역폭이 159 Hz로 좁아지고(Q ≈ 3.2) 공진 봉우리가 뾰족해진다.
3. 해석 종류를 **Transient** 로 바꾸고 `.tran 0.1m 50m`으로 실행한다. `f=100`을 공진 주파수 근처(`f=500`)로 바꿔 가며 출력 진폭을 비교한다.

## 6. 자주 하는 실수

| 증상 | 원인과 해결 |
|---|---|
| AC 해석 결과가 모두 0 | 전원의 `ac` 값이 없다. VSIN의 **Simulation Model…** 에서 AC magnitude를 1로 둔다. |
| 그래프가 계단처럼 보임 | 점이 너무 적다. `dec 10`을 `dec 50`으로 늘린다. |
| 값 `01.uF`의 의미가 헷갈림 | KiCad는 `01.u`를 1.0 µF로 읽는다. `0.1u`와 다르므로 주의한다. |
