# 시뮬레이션 4. Transistor Bias — BJT 동작점(DC Operating Point)

**동작점 해석(Operating Point, `.op`)** 은 신호가 없을 때 회로의 모든 DC 전압과 전류를 한 번에 계산한다.
이 예제에서는 전압 분배 저항으로 NPN 트랜지스터(2N3904)에 바이어스를 걸고, 베이스·컬렉터 전압과 전류를 구한다. 증폭기를 설계할 때 가장 먼저 하는 계산이다.

---

## 1. 회로

```
 12V ──┬───────────┬──────────┐
       │           │          │
      V1 12V     R1 100kΩ   R3 1kΩ
       │           │          │ C
       │           ├──────── B┤ Q1 2N3904
       │         R2 10kΩ      │ E
       │           │          │
 GND ──┴───────────┴──────────┘
```

| 참조 번호 | 부품 | 값 | 역할 |
|---|---|---|---|
| V1 | DC 전압원 (`Simulation_SPICE:VDC`) | 12 V | 전원 |
| R1, R2 | 저항 | 100 kΩ, 10 kΩ | 베이스 전압 분배(바이어스) |
| R3 | 저항 | 1 kΩ | 컬렉터 저항 |
| Q1 | NPN 트랜지스터 | 2N3904 | 모델: [`SpiceModels/2N3904.lib`](../SpiceModels/2N3904.lib) |

### 트랜지스터 모델 연결
Q1은 제조사 SPICE 모델 파일을 불러와 쓴다. Q1을 더블클릭 → **Simulation Model…** 에서 다음을 확인한다.

| 항목 | 값 | 설명 |
|---|---|---|
| Library | `${KIPRJMOD}/../SpiceModels/2N3904.lib` | `${KIPRJMOD}`는 프로젝트 폴더. 상대 경로라서 폴더를 옮겨도 동작한다. |
| Name | `2N3904` | 파일 안의 `.model` 이름 |
| Pin assignment | 1 = E, 2 = B, 3 = C | 심볼의 핀 번호와 모델의 C/B/E를 짝지어 준다 |

> **핀 매핑에 주의한다.** KiCad의 2N3904 심볼은 핀 순서가 **E-B-C**(1=E, 2=B, 3=C)이다. 매핑을 `1=C 2=B 3=E`로 잘못 지정하면 컬렉터와 이미터가 뒤바뀌어 전혀 다른 결과가 나온다.

## 2. 손으로 계산하기

베이스 쪽을 테브난 등가회로로 바꾸면 다음과 같다.

```
V_TH = 12 V × R2 / (R1 + R2) = 12 × 10k / 110k ≈ 1.09 V
R_TH = R1 ∥ R2              = 100k ∥ 10k      ≈ 9.09 kΩ

I_B ≈ (V_TH − V_BE) / R_TH ≈ (1.09 − 0.72) / 9.09k ≈ 41 µA
I_C = β × I_B
V_C = 12 V − R3 × I_C
```

β(hFE)는 트랜지스터마다, 전류마다 다르다(2N3904는 대략 100 ~ 300). 그래서 손 계산만으로는 I_C를 정확히 알기 어렵고, 시뮬레이션이 필요하다.

## 3. 시뮬레이션 실행

1. `TransistorBias.kicad_pro`를 열고 **Inspect → Simulator** 를 연다.
2. 저장된 해석은 **`.op`** 이다.
3. **Run Simulation** (▶)을 누르고, 결과 목록에서 각 넷 전압과 소자 전류를 확인한다.

## 4. 결과

| 항목 | 시뮬레이션 | 비고 |
|---|---|---|
| 베이스 전압 V_B | **0.717 V** | = V_BE |
| 컬렉터 전압 V_C (= V_CE) | **5.10 V** | 0.2 V보다 크므로 **활성 영역**(증폭 가능) |
| 베이스 전류 I_B | **41.2 µA** | 손 계산 41 µA와 일치 |
| 컬렉터 전류 I_C | **6.90 mA** | |
| 전류 이득 β = I_C / I_B | **약 168** | |
| 전원 전류 | **7.01 mA** | I_C + 분배 저항 전류 |

## 5. 해 보기

1. `SpiceModels/2N3904.lib`를 복사해 `BF=416.4`를 `BF=100`으로 바꾼 모델 파일을 만들고, Q1의 Library를 그 파일로 바꿔 시뮬레이션한다.
   이 회로는 이미터 저항이 없어서 **β에 따라 동작점이 크게 흔들린다.** (BF 416 → 100일 때 I_C 6.9 mA → 3.3 mA)
2. 이미터와 GND 사이에 저항 R_E(220 Ω)를 넣고 1번을 반복한다. β를 바꿔도 동작점이 훨씬 덜 변한다(I_C 1.49 mA → 1.23 mA). 이것이 **이미터 저항의 부궤환에 의한 안정화** 이다.
3. R2를 `20k`로 바꾼다. V_C가 약 0.25 V까지 떨어져 트랜지스터가 **포화 영역** 에 들어가는 것을 확인한다. (`15k`에서는 V_C ≈ 1.6 V로 아직 활성 영역이다.)

## 6. 자주 하는 실수

| 증상 | 원인과 해결 |
|---|---|
| 모든 전압이 0 | 전원 심볼(`12V`)만 있고 **전압원이 없다.** 전원 심볼은 이름만 붙일 뿐 전압을 만들지 않는다. `Simulation_SPICE:VDC`를 넣는다. |
| 컬렉터 전류가 음수이거나 이상함 | 트랜지스터 **핀 매핑**이 틀렸다. 1장의 표를 확인한다. |
| 모델 파일을 찾을 수 없다는 오류 | Library 경로를 확인한다. 절대 경로(`C:\...`) 대신 `${KIPRJMOD}` 기준 상대 경로를 쓴다. |
