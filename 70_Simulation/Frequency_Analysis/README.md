# 시뮬레이션 3. Frequency Analysis — RC 저역통과·고역통과 필터

가장 기본적인 1차 필터 두 개를 AC 해석으로 비교한다.
**저역통과 필터(low-pass)** 는 낮은 주파수를 통과시키고, **고역통과 필터(high-pass)** 는 높은 주파수를 통과시킨다. R과 C의 자리만 바꾸면 된다.

> AC 해석의 기본 개념은 [AC_Analysis](../AC_Analysis/)를 참고한다.

---

## 1. 회로

```
 [RC 저역통과]                        [CR 고역통과]
 V1 ──[ R1 1kΩ ]──┬── Vlp            V2 ──┤├────┬── Vhp
                  │                       C2 100nF│
                C1 100nF                        R2 1kΩ
                  │                                │
 0 ───────────────┘                  0 ───────────┘
```

| 참조 번호 | 부품 | 값 |
|---|---|---|
| V1, V2 | 사인파 전압원 (`Simulation_SPICE:VSIN`) | `dc=0 ampl=1 f=1k ac=1` |
| R1, R2 | 저항 | 1 kΩ |
| C1, C2 | 커패시터 | 100 nF |

두 필터는 서로 연결되어 있지 않은 독립된 회로이다. 전원을 따로 두었기 때문에 한 번의 시뮬레이션으로 두 결과를 함께 볼 수 있다.

## 2. 이론

두 필터 모두 차단 주파수(cutoff frequency, 이득이 −3 dB가 되는 주파수)는 같다.

```
fc = 1 / (2π R C) = 1 / (2π × 1k × 100n) ≈ 1.59 kHz
```

| | 저역통과 (Vlp) | 고역통과 (Vhp) |
|---|---|---|
| fc보다 훨씬 낮은 주파수 | 0 dB (그대로 통과) | 10배 내려갈 때마다 −20 dB |
| fc | −3 dB, 위상 −45° | −3 dB, 위상 +45° |
| fc보다 훨씬 높은 주파수 | 10배 올라갈 때마다 −20 dB | 0 dB (그대로 통과) |

"10배마다 −20 dB"를 **−20 dB/decade** 라고 하며, 1차 필터의 특징이다.

## 3. 시뮬레이션 실행

1. `Frequency_Analysis.kicad_pro`를 열고 **Inspect → Simulator** 를 연다.
2. 저장된 해석은 **`.ac dec 20 10 1meg`** 이다. 10 Hz ~ 1 MHz를 10배마다 20개 점씩 계산한다.
   `meg`는 메가(10⁶)이다. SPICE에서 `m`/`M`은 밀리(10⁻³)이므로 주의한다.
3. **Run Simulation** (▶)을 누른다. `V(/Vlp)`와 `V(/Vhp)`의 이득이 등록되어 있다. 위상도 보려면 **Add Signals** 에서 phase를 추가한다.

## 4. 결과

| 항목 | 시뮬레이션 | 계산값 |
|---|---|---|
| 저역통과 −3 dB 주파수 | **1.59 kHz** | 1.59 kHz |
| 고역통과 −3 dB 주파수 | **1.59 kHz** | 1.59 kHz |
| 저역통과, 15.9 kHz (fc × 10) | **−20.0 dB** | −20 dB |
| 저역통과, 159 kHz (fc × 100) | **−40.0 dB** | −40 dB |
| 고역통과, 159 Hz (fc ÷ 10) | **−20.1 dB** | −20 dB |
| 저역통과 위상, fc | **−45°** | −45° |

## 5. 해 보기

1. R1을 `10k`로 바꾼다. 저역통과의 fc가 159 Hz로 내려가는 것을 확인한다.
2. 저역통과 뒤에 같은 RC를 한 단 더 붙여 **2차 필터** 를 만든다. 기울기가 −40 dB/decade로 바뀌는지 확인한다.
3. [AC_Analysis](../AC_Analysis/)의 RLC 대역통과 결과와 비교해 본다. 저역통과와 고역통과를 합친 모양인지 생각해 본다.
